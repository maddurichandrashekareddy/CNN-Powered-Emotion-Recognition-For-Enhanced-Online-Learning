# CNN Powered Emotion Recognition for Enhanced Online Learning

# Objective
To develop a real-time emotion detection system that enhances online learning by identifying student states such as **Listening, Not Listening, Bored, and Confused** using Convolutional Neural Networks (CNNs).

# Features
- Real-time face detection using OpenCV
- CNN-based emotion classification
- Visualization with live emotion charts (Pie + Bar)
- Start/Stop video controls for monitoring sessions

# Technologies Used
 Languages - Python, HTML, CSS, JavaScript 
 Frameworks | TensorFlow / Keras, Flask |
 Datasets | FER2013, JAFFE, KDEF |
 Libraries | OpenCV, NumPy, Matplotlib |
 Platforms | Jupyter Notebook / VS Code |

# Performance Metrics
- Accuracy: 87.3%
- Precision: 84.9%
- Recall: 86.1%
- F1 Score: 85.5%
